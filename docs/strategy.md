# استراتژی چندتایم‌فریمی MACD

این متن، استراتژی‌ای است که بردیا با ویدیو و عکس (XAUUSD، ۴ تا ۱۴ نوامبر ۲۰۲۶، MT4) توضیح داد.
ربات فعلی (`bot/strategy.py`) فقط پله‌ی آخر آن را اجرا می‌کند: واگرایی روی M1، بدون فیلتر تایم‌های بالاتر.

> وضعیت: **نسخه‌ی شهودی**. تعریف‌های دقیق (برای کد) هنوز باید یکی‌یکی مشخص شوند؛ بخش «سؤال‌های باز» را ببینید.

## پایه

- **هیستوگرام** در اینجا یعنی خط MACD (EMA سریع منهای EMA کند)، مثل MT5.
- **قدر مطلق هیستوگرام زیاد می‌شود ← روند. کم می‌شود ← اصلاح.** فارغ از اینکه واگرایی هست یا نه.
- روی هر چارت سه MACD هست که در واقع سه تایم‌فریم‌اند:

  | روی چارت | معادل (12,26,9) روی |
  |---|---|
  | (48,104,36) — ۴ برابر | تایم ۴ برابر بزرگ‌تر |
  | (12,26,9) — پیش‌فرض | همان تایم |
  | (3,6,2) — یک‌چهارم | تایم ۴ برابر کوچک‌تر |

  مثال: روی دیلی ← ۴ روزه / دیلی / ۶ ساعته. روی H4 ← ۱۶ ساعته / H4 / H1. روی H1 ← H4 / H1 / M15.
- (تجربی) نتیجه‌ی هر چیزی که در MACD دیده می‌شود، حدود **۱۰ تا ۲۰ کندلِ همان تایم‌فریم** بعد دیده می‌شود.

## ۱. جهت — دیلی

- **(3,6,2) دیلی سقف بدهد ← فروش. کف بدهد ← خرید.** این جهتِ دی‌ترید برای چند روز آینده است.
- روی ناحیه‌ی آن سقف/کف یک **مستطیل** کشیده می‌شود تا در تایم‌های پایین‌تر دیده شود.
- (48,104,36) دیلی تصویر بزرگ است (مثلاً «هنوز واگرایی صعودی نداده، پس روند نزولی تمام نشده»). ممکن است ۵۰ روز طول بکشد؛ برای دی‌ترید منتظرش نمی‌مانیم.

## ۲. ورود اول — شروع حرکت

- **سقف اول جدی گرفته نمی‌شود.** تا وقتی MACD پیش‌فرض تایم پایین‌تر واگرایی نداده، ریزش بعد از سقف اول فقط اصلاح است.
  (مثال: سقف اول ۴–۵ نوامبر، (12,26,9) H1 فقط یک سقف داشت ← فقط یک ریزش کوچک تا ~۴۰۴۰ و برگشت به مستطیل.)
- **(12,26,9) روی H4 = (48,104,36) روی H1 باید واگرایی بدهد**، هم‌جهت با دیلی.
  (مثال: سقف دوم ۹–۱۰ نوامبر: قیمت هم‌اندازه/بالاتر، MACD ضعیف‌تر ← ریزش بزرگ تا ~۳۸۸۰.)
- (48,104,36) H4 می‌گوید در کدام مرحله‌ایم: مثلاً اگر هنوز «سقف میانی» نساخته، ریزش بزرگ هنوز زود است.
- سپس تایم‌ها پله‌پله شکسته می‌شوند (H1 ← M15 ← M5 ← M1) و **مستطیل تنگ‌تر** می‌شود.
- در تایم‌های پایین **فقط سیگنال‌های هم‌جهت** و **فقط داخل مستطیل** پذیرفته می‌شوند.
- **ورود:** واگرایی نهایی روی M1. از ابتدای حرکت تا انتهای آن.

## ۳. ورودهای بعدی — وسط حرکت

- وقتی قدر مطلق (48,104,36) H4 در جهت معامله **زیاد** می‌شود (سقف میانی داده شده، فاز روند)،
  **هر سقف (3,6,2) روی M5 یک فروش دوباره است** (برای خرید: هر کف). واگرایی لازم نیست.

## ۴. خروج

- وقتی **(3,6,2) دیلی برعکس شود** (برای فروش: کف بدهد) و روی MACD چهار برابری H1 یا H4 **سناریوی برعکس** دیده شود.
- همان نقطه، شروع سناریوی معامله‌ی مخالف است.

## سؤال‌های باز (برای کد کردن)

1. «(3,6,2) دیلی سقف داد» دقیقاً کِی تأیید می‌شود؟ (کندل بسته‌شده یا کندل در حال تشکیل؟ سقف باید بالای صفر باشد؟)
2. مستطیل دقیقاً از کجا تا کجاست؟ (قیمت و زمان)
3. واگرایی H1/H4 حتماً باید داخل مستطیل باشد؟
4. «هر سقف (3,6,2) M5» — هر سقفی، یا فقط سقف‌های بالای صفر؟ تا کِی؟
5. حد ضرر؟
6. جاها/زمان‌هایی که وارد نمی‌شوی (اخبار، ساعت خاص، آخر هفته)؟
